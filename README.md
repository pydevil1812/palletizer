# Pallet Stacking Studio

Калькулятор раскладки коробок на паллете: React-фронтенд (виды 3D/сверху/сбоку/таблица,
экспорт в PDF/Excel/JSON, история запросов), который обращается к бэкенду на Python/Flask,
выполняющему все расчёты раскладки.

## Запуск

```
start.bat
```

Это единственная команда, которая нужна. При первом запуске устанавливаются зависимости
бэкенда (`pip install -r palletizer_source/requirements-server.txt`) и фронтенда
(`npm install`), после чего открываются два окна:

- API/вычислительный бэкенд по адресу `http://127.0.0.1:5000`
- сам сайт по адресу `http://localhost:5173` — откройте его в браузере

При последующих запусках шаг установки пропускается, и сайт стартует за несколько секунд.
Чтобы остановить сайт, закройте оба окна (или нажмите Ctrl+C в каждом из них).

### Требования

- Python 3.9+ с `pip` в PATH
- Node.js с `npm` в PATH

## Структура

- `front/` — React-приложение (Vite). Все вычисления убраны с этой стороны;
  оно только отображает то, что возвращает API.
- `palletizer_source/` — Flask API: `server.py` предоставляет эндпоинты
  `/api/compute` (раскладка упаковки) и `/api/history` (сохранённая история
  запросов, хранится в файле SQLite, создаваемом при первом использовании).
