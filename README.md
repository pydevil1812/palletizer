# palletization

## Назначение

Инструмент расчёта паллетизации: он подбирает размещение одинаковых коробок на паллете, оценивает слои, высоту, вес и формирует понятные рекомендации и отчёты.

## Возможности

- перебор допустимых ориентаций коробки;
- расчёт 2D-раскладки одного слоя и 3D-стопки слоёв;
- контроль ограничений паллеты по габаритам, высоте и массе;
- рекомендации по улучшению заполняемости;
- визуализации и выгрузка результатов в Excel, PDF и HTML;
- запуск через CLI, графический интерфейс или веб-интерфейс из папки `front/`.

## Структура

```text
palletizer_source/palletizer/
  models.py          # модели коробки, паллеты и результатов
  packer.py          # алгоритм раскладки
  visualization.py   # 2D/3D-визуализации
  report.py          # экспорт отчётов
  cli.py             # консольный вход
front/               # браузерный интерфейс
run_app.py           # запуск приложения
example_input.json   # пример входных данных
```

## Запуск

Установите зависимости, указанные в проекте, и используйте пример конфигурации:

```bash
python run_app.py
```

Для консольного сценария подготовьте JSON по образцу `example_input.json` и передайте его CLI согласно справке проекта.

## Технологический стек

- Python
- алгоритмы упаковки и модели данных
- Matplotlib для визуализации
- Pandas/экспорт офисных форматов
- HTML, CSS, JavaScript для интерфейса

## Статус и ограничения

Текущий алгоритм рассчитан прежде всего на одинаковые коробки. Смешанные SKU и расширенная работа с прокладками обозначены в коде как будущие точки развития; результаты следует сверять с реальными производственными ограничениями.
